# European Soccer Player Analytics

A data analytics portfolio project focused on evaluating player
performance across La Liga and the UEFA Champions League.

## Project Goal

Analyze soccer player performance using position-specific metrics,
playing time, per-90 statistics, expected metrics, and competition
context.

## Initial Scope

- 2025-26 La Liga
- 2025-26 UEFA Champions League
- Forwards
- Midfielders
- Defenders
- Goalkeepers

## Planned Technologies

- Python
- SQL
- PostgreSQL
- Tableau
- Excel
- Git
- GitHub

## Planned Analysis

The project will investigate:

- Player performance by position
- Totals versus per-90 production
- Expected goals and expected assists
- Domestic versus Champions League performance
- Player comparisons
- Position-specific leaderboards
